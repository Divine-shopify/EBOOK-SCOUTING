## How the initial campaign was run (read this before using the leads)

- **Discovery, part 1 (batch 1, 51 seeds):** no web-search API key was configured, so seed discovery was done with Claude Code's own WebSearch/WebFetch tools. There were four region segments: US/CA, UK/IE/AU/NZ, continental Europe, and APAC/ME plus serial platforms. The seeds are committed in `seeds/`. Nothing in a seed is trusted as-is: the pipeline re-fetched every permitted URL, re-derived review counts, status, country, identity and emails, and recorded anything it could not confirm as an error.
- **Discovery, part 2 (batch 2):** fully automated through the app's own Open Library search adapter (16 live queries, 46 result URLs, 35 candidates), plus the one seed that didn't fit in batch 1.
- **Review filter (≤ 1,000, inclusive):** the filter uses the larger of Goodreads *ratings* and *reviews* on the inspected listing. Books above the ceiling, and published books with no observable count, were skipped. The ceiling is per book, so an author can have one qualifying book and other books above 1,000 (Chani Lynn Feener, Aaron Hodges, Joan Fallon, Michael Pronko, Brooke Marley Jones, K. Godin).
- **HTTP call counts:** the counts shown per run are low because pages fetched during earlier development runs were served from the 72-hour cache.

## Known limitations of this run

- **No email is "verified" in the strong sense.** All 14 addresses are publicly listed on the author's own site. Syntax and MX checks pass (`domain_mx_checked`). No ZeroBounce or NeverBounce key was configured, so `provider_verified` is 0 and `contacts_verified.csv` is empty, as expected.
- **Reference-only platforms.** Amazon, Kobo, Kickstarter and Royal Road block automated clients. Their URLs are stored as reference evidence, not inspected. Most Kickstarter-only projects (Helga Viegas, Pablo Di Francesco, Madelaine Salvage, Elizabeth Daly) therefore stay at status `unclear`.
- **Country is left blank** for 9 authors whose claimed country no fetched page confirmed (for example Talia May, whose Impressum uses a c/o service address).
- **Book inspection.** Only listings were inspected (`inspection_scope = listing_only`). No book content was read.
- **Not configured:** the AI analysis pass (no `ANTHROPIC_API_KEY`), keyed web search (Brave, Tavily, SerpAPI), and Google Books (the keyless quota returned HTTP 429).
- **Failures:** Todd Sullivan and Lyse Beck could not be verified because every source was blocked or reference-only. They are recorded as failed, with nothing stored.
